- (decision) Hexagonal domain core separates canonical content and command rules from AWS adapters, preventing vendor-specific identities in exports.
- (decision) Publishing snapshots one immutable revision per locale and atomically records an outbox event, preventing draft leaks and missing/duplicate downstream effects.
- (assumption) Runtime, identity provider, exact DynamoDB schema and live deployment are deferred until later-day evidence and user decisions.
